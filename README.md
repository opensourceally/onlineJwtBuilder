# Online JSON Web Token Builder

Node.js-based web application used to generate signed valid JSON Web Tokens to be used for testing. You can include both standard and custom claims, as well as specify your own symmetric signing key.

### Future Plans

- Saving form data to browser local storage
- "Import Token" button, to populate the claims from an existing token

The live site for this application is here: [jwtbuilder.jamiekurtz.com](http://jwtbuilder.jamiekurtz.com)

---

## Developer Guide

1. Ensure [Node.js](https://nodejs.org/) is installed
1. Run `npm install` from this project folder to install and configure all dependencies
1. Run `npm start` to start the server
1. Browse to `http://localhost:3000` to view the site
